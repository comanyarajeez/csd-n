## 🚀 كيفية استخدام الموقع

### 1. **التشغيل المحلي**
ببساطة افتح ملف `index.html` في متصفح الويب:
```bash
open index.html
# أو اضغط مباشرة على الملف من File Manager
```

### 2. **النشر على الإنترنت**
ارفع الملفات إلى أي خادم ويب:
```bash
- استضافة مشهورة: GoDaddy, Bluehost, HostGator
- منصات مجانية: GitHub Pages, Netlify, Vercel
```

### 3. **التخصيص والتعديل**
- تعديل الألوان: غير `--accent` في `style.css`
- تغيير النصوص: عدّل `index.html` مباشرة
- إضافة صور: ضع الصور في مجلد `assets/images/`
